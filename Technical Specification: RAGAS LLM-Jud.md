# Technical Specification: RAGAS LLM-Judge Reliability Study

## 1. Project Objective

Evaluate the reliability of RAGAS metrics (**Faithfulness, Answer Relevance, Answer Correctness**) by comparing scores generated by three distinct LLM Judges across four controlled dataset variants derived from `vibrantlabsai/WikiEval`.

---

## 2. Dataset Specification

**Source:** https://huggingface.co/datasets/vibrantlabsai/WikiEval  
**Sample Size:** N=50

### Key Columns & Mapping Logic

| Variant               | Logic                        | Dataset Column Mapping                        |
| --------------------- | ---------------------------- | --------------------------------------------- |
| **A (Gold)**          | High-quality triple          | `question`, `context_v1`, `answer`            |
| **B (Hallucination)** | Ungrounded answer            | `question`, `context_v1`, `ungrounded_answer` |
| **C (Poor Quality)**  | Low relevancy answer         | `question`, `context_v1`, `poor_answer`       |
| **D (Noisy)**         | Irrelevant/Redundant context | `question`, `context_v2`, `answer`            |

---

## 3. Implementation Phases

### Phase 1: Environment & Data Engineering (`data_prep.py`)

- **Setup:**

  - Python 3.10+
  - Install:
    ```bash
    pip install ragas datasets pandas scipy python-dotenv
    ```

- **Loading:**

  - Load dataset `vibrantlabsai/WikiEval` (split: `train`)

- **Data Structuring:**

  - Convert `context_v1` and `context_v2` to Python lists (required by RAGAS)
  - Generate four CSV files:
    ```
    data/variants/A.csv
    data/variants/B.csv
    data/variants/C.csv
    data/variants/D.csv
    ```

- **Bias Mitigation (Verbosity):**
  - Compute average length of:
    - `answer`
    - `ungrounded_answer`
    - `poor_answer`
  - If difference > 20%:
    - Apply truncation to normalize lengths
